# MVP-Pipeline de Dados na Nuvem


Aluna: Larissa Mitrof de Lima <br>
Curso: Ciência de Dados e Analytics - PUC-Rio <br>
Sprint: Engenharia de Dados <br>
Tema: Análise Descritiva das Ordens de Manutenção na Indústria Farmacêutica

Pipeline de dados construído no Databricks (arquitetura em camadas Bronze, Silver e Gold) a partir de ordens de manutenção de uma indústria farmacêutica, com modelagem em esquema estrela, catálogo de dados, tratamento de qualidade e análise das 5 perguntas de negócio propostas. O relatório completo, com todas as evidências, está em [Relatorio_MVP_Pipeline.pdf](./Relatorio_MVP_Pipeline.pdf).
